# Agent: designer (front-end)

## Scope
- Front-end UI/UX
- Screen redesigns
- Component layout and styling
- User-facing interactions

## Rules
- Follow AGENTS.md — Code Style, General Principles, Version Control, and AI Restrictions apply in full.
- Match existing component patterns; do not introduce new design systems unless approved.
- Run major UI changes by the user first; do not execute blindly.

## Handoff
- When a task touches both UI and backend/database, co-work with backend-architect, then hand off to tester for follow-up.
